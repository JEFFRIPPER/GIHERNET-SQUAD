GNIREHTET SQUAD 1.0.0 — графическая оболочка для gnirehtet 2.5.1
================================================================

Раздаёт интернет компьютера на Android-телефон по USB (reverse tethering).
Root на телефоне не нужен.

БЫСТРЫЙ СТАРТ
1. Распакуйте папку целиком (GnirehtetSquad.exe должен лежать рядом с gnirehtet.exe и gnirehtet.apk).
2. На телефоне включите «Параметры разработчика → Отладка по USB», подключите кабель.
3. Запустите GnirehtetSquad.exe.
4. Если adb не найден — нажмите «Скачать platform-tools» (официальный архив Google, ~7 МБ,
   ставится в папку platform-tools рядом с программой).
5. Нажмите большую красную кнопку. На телефоне подтвердите запрос VPN.

ЧТО УМЕЕТ
- Старт/стоп/перезапуск relay одной кнопкой, режимы «Все устройства» (autorun) и «Одно устройство».
- Список устройств с моделями и статусами (готово / нужно разрешить отладку / offline),
  включение и отключение VPN на каждом телефоне, установка/переустановка/удаление APK.
- Подключение по Wi-Fi (adb connect), перезапуск adb-сервера.
- Живой журнал с фильтрами, поиском, копированием и сохранением в файл.
- Счётчик подключённых клиентов, время работы, автоперезапуск при падении relay.
- Настройки DNS (пресеты Cloudflare / Google / Quad9 / AdGuard / Яндекс), маршруты, порт, путь к adb.
- Отключение VPN на телефонах при остановке (не остаётся «мёртвый» значок VPN).
- Проверка занятого порта и кнопка «Завершить зависшие процессы».
- Работа в фоне после закрытия окна, автозагрузка вместе с Windows (relay стартует сразу).
- Один экземпляр: повторный запуск просто открывает окно.

ОКНО
Интерфейс открывается отдельным окном Microsoft Edge (есть в любой Windows 10/11) в режиме
приложения, без адресной строки. Если Edge нет — Chrome/Brave, иначе браузер по умолчанию.
Закрытие окна завершает программу и останавливает relay (если не включена работа в фоне).

ФАЙЛЫ
- Настройки: %APPDATA%\GnirehtetSquad\settings.json
- Исходники: https://github.com/JEFFRIPPER/GIHERNET-SQUAD
- gnirehtet-run.cmd — оригинальный консольный запуск, оставлен как запасной вариант.

Параметры командной строки:
  GnirehtetSquad.exe --background   без окна, сразу запустить relay (используется автозагрузкой)
