GNIREHTET SQUAD — интернет компьютера на Android по USB
================================================================

Раздаёт интернет компьютера на Android-телефон по USB (reverse tethering, gnirehtet 2.5.1).
Root на телефоне не нужен. Обычная Windows-программа: один GnirehtetSquad.exe,
.NET и браузер не нужны, gnirehtet.exe и gnirehtet.apk уже внутри.

БЫСТРЫЙ СТАРТ
1. На телефоне включите «Параметры разработчика → Отладка по USB», подключите кабель.
2. Запустите GnirehtetSquad.exe.
3. Если adb не найден — нажмите «Скачать platform-tools» (официальный архив Google, ~7 МБ).
4. Нажмите большую красную кнопку. На телефоне подтвердите запрос VPN.

ЧТО УМЕЕТ
- Старт/стоп/перезапуск relay одной кнопкой, режимы «Все устройства» (autorun) и «Одно устройство».
- Список устройств с моделями и статусами, включение и отключение VPN на каждом телефоне,
  установка/переустановка/удаление APK.
- Подключение по Wi-Fi (adb connect), перезапуск adb-сервера.
- Журнал с фильтрами и поиском.
- Счётчик подключённых клиентов, время работы, автоперезапуск при падении relay.
- Настройки DNS (пресеты), маршруты, порт, путь к adb.
- Отключение VPN на телефонах при остановке.
- Значок в трее и работа в фоне, автозагрузка вместе с Windows.
- Один экземпляр: повторный запуск открывает окно уже работающей программы.
- Обновления по воздуху: программа сама находит новую версию на GitHub и ставит её
  в один клик (или автоматически, включается в Настройках).

ФАЙЛЫ
- Настройки: %APPDATA%\GnirehtetSquad\settings.json
- Исходники: https://github.com/JEFFRIPPER/GIHERNET-SQUAD

Параметры командной строки:
  GnirehtetSquad.exe --background   без окна, сразу запустить relay (используется автозагрузкой)
