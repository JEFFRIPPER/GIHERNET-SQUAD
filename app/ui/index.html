Устройства

Определяются автоматически через adb. В режиме «Все устройства» VPN включается на каждом подключённом телефоне.

Готовность

Проверка всего, что нужно для работы.

Последние события

Подключённые устройства

Управление VPN и приложением gnirehtet на каждом устройстве отдельно.

Подключение по Wi-Fi (adb tcpip)

Телефон и ПК в одной сети, на телефоне включена беспроводная отладка.

Если устройство не видно

  1. Включите Параметры разработчика → Отладка по USB.
  2. Используйте кабель с передачей данных, не только зарядкой.
  3. Статус «нужно разрешить» — подтвердите запрос RSA на экране телефона.
  4. Не помогло — «Перезапустить adb» выше.

Сеть

DNS-серверы, которые получит телефон, и маршруты через ПК.

Пусто = весь трафик. Пример: 192.168.0.0/16,10.0.0.0/8
По умолчанию 31416

Поведение

Изменения применяются сразу.
